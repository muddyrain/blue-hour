# 蓝时归航（Blue Hour）设计定稿

本文记录已锁定的美术方向、HUD 规范、玩法支柱、首个关卡类型与路线图。仓库现状结构见 `architecture.md`。

## 0. 原创规则（clean-room）

- 玩法参考 Deadly Days 的**机制**（多人小队指挥、出车搜刮、天黑压力、回车撤离、营地经营），只复刻规则，不复刻表现。
- 不使用 Deadly Days 的任何图像、音频、录屏、UI 文案或标志物（包括黄色校巴、LOOT 横幅样式）。
- 所有美术、文案、图标为本项目原创（AI 辅助生成需登记到 `assets/PROVENANCE.json`）。

## 1. 美术方向（已锁定）

参考图：`docs/art/target_hud.jpg`（白天）。图中文字是 AI 占位，正式版一律由代码渲染。

- **镜头**：严格 2.5D 等距（2:1 菱形网格，道路/墙/屋顶沿两条约 26.6°/30° 斜线对齐），固定俯视指挥镜头，可平移/缩放，不旋转。
- **场景**：日本海边小镇。街道、斑马线、运河与石拱桥、电车站、便利店、自动售货机、行道树、路灯、自行车。
- **建筑**：屋顶封闭，**不能进入建筑、没有室内**（与原作一致）。搜刮在建筑门口/地块标记点完成。
- **角色**：小比例 Q 版二次元少女，日常服装（卫衣、雨衣、制服、背带裤等），健康向，不走性感路线。头顶小字显示名字。
- **僵尸**：暗灰绿低饱和剪影，与角色在明度上拉开，夜间更难辨认。
- **搜刮点**：地面琥珀色菱形标记（不用横幅）。
- **昼夜**：地图随一天的计时逐渐变暗：
  - 整个世界层叠一层逐渐加深的蓝色调（CanvasModulate），HUD 不受影响；
  - 路灯、售货机、店铺窗户、巴士车灯是暖色点光源，夜里亮起；
  - 屏幕边缘压暗（暗角），入夜后加强；
  - 入夜后僵尸数量与刷新速度上升。
- **实现方式**：地面拆成等距瓦片（TileMapLayer 等距模式），房子/桥/售货机/灯等是独立贴图，按"一块地砖、一栋房子"分批出图。

## 2. HUD 规范

整体：暖炭灰半透明面板，不用扁平藏青色（避免 demo 感）。

| 元素 | 取值 |
| --- | --- |
| 面板底 | `#22201e`，不透明度约 80% |
| 边框 | 1px 奶白 `#e8dcc4`（约 55% 透明），小切角/2–3px 圆角，淡阴影 |
| 主强调色 | 低饱和琥珀 `#d9a24a`（标题、进度、选中） |
| 血量 | 鼠尾草绿 `#8fbf7a`，受伤转琥珀，残血红 `#c8553d` |
| 文字 | 主 `#e8dcc4`，次 `#b8ac96`；全部简体中文 |

布局（1280×720 基准，锚点适配）：

- **左上 任务面板**：贴顶，不留 logo 位。头部是关卡/任务名；下面是当前目标 + 进度；再下面是可选目标勾选清单。
- **顶部中间 天数条**：第 N 天、通向入夜的进度条、距天黑倒计时、危险等级/入夜状态。必须用普通进度条控件就能实现，不做花哨天幕。
- **右上 资源栏**：按游戏实际资源显示（当前代码里是 货币 / 食物 / 工具箱，以及携带物），右侧是菜单/暂停按钮。
- **右侧 幸存者列表**：每人一行：小头像、名字、HP 数字 + 血条。头像不加彩色边框。选中者高亮。数字键快速选人。
- **左下 方形小地图**：显示地点名（如"海边町·商店街路口"）、幸存者点、巴士点；角上挂一个小巴士按钮（快捷键 B）= 一键全员回巴士。
- **底部中间 4 个指令按钮**：圆角方块，图标 + 文字 + 快捷键，冷却时外圈琥珀进度。
- **出发**：没有大"返回"按钮。巴士周围有琥珀色登车光圈（沿用 `boarding_radius`），全员走进光圈后进度环转满即出发。

## 3. 玩法支柱

一局循环（Deadly Days 式多人小队指挥）：

1. **出车**：在营地选择当天行动，坐小巴前往一个地点。
2. **搜刮**：天黑前派队员到地图上标记的搜刮点（多人一起更快），获取食物、货币、工具与武器。
3. **生存**：时间推进，危险等级上升；入夜后僵尸增多、视野变窄。指挥小队集合、集火、治疗、用特技。
4. **撤离**：全员回到巴士登车光圈，发车离开；没回来的人会被留下。
5. **营地**：结算带回的物资，喂饱全队（人越多吃得越多），建造/升级设施、修理改装武器、招募幸存者，第二天再出发。

设计原则：

- 每局 5–10 分钟，"再贪一个点还是现在走"是核心抉择。
- 小队上限目标 8 人（当前代码 `RosterState.MAX_LIVING = 4`，标记为 PROJECT_TEMP；本轮不改，另开 PR 处理右侧列表与数字键 1–8）。
- 数值都是临时值，改动在 PR 中说明。

## 4. 首个关卡类型："海边町·商店街路口"

尺寸：约 3×3 个街区的等距地图，一屏看到约 1/3。

分区：

| 区域 | 内容 | 作用 |
| --- | --- | --- |
| 中央路口 | 十字路口、斑马线、电车站台、巴士停靠点 | 出生点与登车光圈，开阔、好集合 |
| 商店街（东北） | 便利店、售货机 ×2、杂货铺 | 食物主搜刮点，路灯多，夜里最亮 |
| 运河与石桥（东/东南） | 运河把地图分成两半，只有石桥和一座小木桥能过 | 天然瓶颈，适合集火守桥；也会把队伍拆散 |
| 住宅巷（西/南） | 低矮民宅、自行车棚、小神社 | 可选搜刮点（工具、废料），巷子窄、视野差 |
| 港口仓库（远端） | 码头、集装箱、渔具仓库 | 高价值点（武器/工具箱），离巴士最远，风险最大 |

搜刮点（示例，最终数量由生成器决定）：便利店（食物）、售货机 ×2（少量食物，快）、杂货铺（货币）、自行车棚（工具）、港口仓库（武器/工具箱，耗时长）。

僵尸压力（随时间）：

- **白天前段**：零散游荡者，集中在住宅巷和港口；
- **黄昏**（倒计时后 1/3）：危险等级上升，从地图边缘和运河两岸持续刷新，开始向噪音/队伍聚集；
- **入夜**：刷新加快、出现成群，主要从远端涌向中央路口；路灯下视野好，暗处看不清；
- 撤离时巴士发动会吸引附近僵尸，登车光圈需要有人守。

登车区域：中央路口的巴士，车头朝向主路，车灯在夜间照亮前方扇形区域；小地图上始终显示巴士图标。
