# 蓝时归航（Blue Hour）设计定稿

本文记录当前美术方向、界面规范、玩法支柱与关卡设计。实现结构见 `architecture.md`；本文不作为运行、导出或人工观感验收记录。

## 0. 原创规则（clean-room）

- 玩法参考 Deadly Days 的**机制**（多人小队指挥、出车搜刮、天黑压力、回车撤离、营地经营），只复刻规则，不复刻表现。
- 不使用 Deadly Days 的任何图像、音频、录屏、UI 文案或标志物（包括黄色校巴、LOOT 横幅样式）。
- 场景、角色、文案与图标为本项目原创（AI 辅助生成需登记到 `assets/PROVENANCE.json`）；第三方字体单独登记来源和许可。

## 1. 美术方向：A 冷调像素

当前采用深蓝界面、蓝灰结构、薄荷状态与珊瑚主操作。首页使用灰蓝海边小镇像素背景 `assets/ui/pixel/title-coast.png`，菜单、标题和动态信息由 Godot 控件独立渲染。旧暖炭灰、琥珀主强调与禁用藏蓝的界面规范已被本节取代。

本轮落地范围是六个真实界面的 UI 与首页像素背景。营地和出击地图沿用既有地面、建筑、人物等独立场景素材；改变 UI 主题不代表整个世界已完成像素重绘。真实场景继续遵循以下边界：

- **镜头**：严格 2.5D 等距（2:1 菱形网格，道路/墙/屋顶沿两条约 26.6° 斜线对齐），固定俯视指挥镜头，可平移/缩放，不旋转。
- **场景**：日本海边小镇。街道、斑马线、运河与石拱桥、电车站、便利店、自动售货机、行道树、路灯、自行车。
- **建筑**：屋顶封闭，**不能进入建筑、没有室内**（与原作一致）。搜刮在建筑门口/地块标记点完成。
- **角色**：小比例 Q 版人物，沿用既有姓名、ID、性别、服装与外观识别特征。顾予安（`member_id = 1`）为男，夏之遥（`member_id = 2`）为女；其余身份以 `src/features/survivors/crew_*.tres` 为准。头顶小字显示名字。
- **僵尸**：暗灰绿低饱和剪影，与角色在明度上拉开，夜间更难辨认。
- **搜刮点**：沿用现有地面标记与门口作业提示，不以界面换色改变任务位置或交互规则。
- **昼夜**：地图随一天的计时逐渐变暗：
  - 整个世界层叠一层逐渐加深的蓝色调（CanvasModulate），HUD 不受影响；
  - 路灯、售货机、店铺窗户、巴士车灯是暖色点光源，夜里亮起；
  - 屏幕边缘压暗（暗角），入夜后加强；
  - 入夜后僵尸数量与刷新速度上升。
- **实现方式**：地面按共用等距投影绘制，房子、桥、售货机、灯与人物使用独立素材，保留闭合屋顶、脚点排序和世界层光照。营地场景等比缩放，维持 2:1 几何。

## 2. UI 规范与六个界面

颜色以 `CampStyle` 当前常量为准。面板、按钮和列表使用方角，通过深浅底色和间距分层；边框用于必要分隔、焦点与选择状态，不加柔光或厚重投影。

| 元素 | 当前取值与用途 |
| --- | --- |
| 背景 / 面板 | 深蓝 `#0a2133` / `#163248` |
| 次级控件 / 选中底色 | 蓝灰 `#315773` / 蓝色 `#4387b7` |
| 必要边界 | 灰蓝 `#527da0`；常规控件无边框，焦点用细线 |
| 生命条 / 正向状态 / 焦点 | 薄荷 `#79edc7`；同时保留 HP 数字、状态文案或选择标记 |
| 主操作 | 珊瑚 `#f36d60`，用于继续、确认、保存等当前主操作 |
| 警告 / 危险 | `#f2c37f` / `#ff9388`，配合原因与数值 |
| 文字 | 主 `#f5f7fa`，次 `#b8c6d4`；以简体中文为主 |

UI 使用清楚的中文无衬线字形，正文沿用系统中文字体回退。首页中文标题使用随包的 Source Han Sans SC Heavy，通过 `FontVariation` 做倾斜；英文副标题保持字距。字体原文件来自 Adobe 官方仓库，未经修改，采用 SIL Open Font License 1.1，许可见 `assets/fonts/SourceHanSans-LICENSE.txt`。标准导出预设包含该许可文本；字体许可不替代仓库自身的授权声明。

布局以 `1280×720` 为基准，`1024×576` 为缩小窗口检查尺寸。文字、列表容量、焦点和键鼠输入须在真实界面验证，不能把概念图缩小视为适配通过。

| 界面 | 当前布局与交互边界 |
| --- | --- |
| 首页 | 灰蓝像素海岸背景，左侧独立标题与菜单；珊瑚色继续入口，下方为新旅程、设置、专精 / 图鉴和退出。继续、备份与重试仍由实际存档状态决定。 |
| 营地 | 上方资源与功能导航，右侧有界滚动队员栏显示头像、姓名、HP 数字和薄荷生命条；中心保留真实 `CampSceneWorld` 院落及设施入口，沿用原建设、补给、训练、配装和任务选择意图。 |
| 出击 HUD | 顶部时间与资源，左上任务目标，右侧队员栏，左下小地图与巴士操作，底部集合 Q、集火 W、治疗 E、特技 R。B 发动巴士或集合至巴士；方向键平移镜头，滚轮缩放。头像只打开人物资料，不提供单位选择。 |
| 声音设置 | 压暗后景的单层居中面板；总音量、世界音效、界面音效三组滑杆和百分比，加总静音、显式保存与返回。调整立即生效；未保存时明确提示，返回不自动写盘，成功或失败分别显示结果。 |
| 装备仓 | 左侧库存、状态 / 类型筛选、名称 / 实例编号搜索；右侧目标队员与当前 / 拟配属性对照。全部类型可混合枪械与近战，筛选后只显示匹配结果；配给、维修和改装仍经原确认与保存流程。 |
| 准备出击 | 左侧行动卡比较目标、路线与风险，右侧复核当前行动、同行与装备；选择卡片后再确认出击。当前选择保留文字与边界标记；收益按原归航结算规则确认，不因选卡直接入账。 |

禁用态保留可读文字与原因；未保存状态就近说明并保留明确保存入口。队员资料与装备比较读取既有数据，不因视觉方向修改身份、成长、武器或任务规则。界面示例和新增数值均为 `PROJECT_TEMP`，不是原作精确事实。

## 3. 玩法支柱

一局循环（Deadly Days 式多人小队指挥）：

1. **出车**：在营地选择当天行动，坐小巴前往一个地点。
2. **搜刮**：天黑前派队员到地图上标记的搜刮点（多人一起更快），获取食物、货币、工具与武器。
3. **生存**：时间推进，危险等级上升；入夜后僵尸增多、视野变窄。指挥小队集合、集火、治疗、用特技。
4. **撤离**：发动巴士，全体存活队员回到登车区域后归航；搜集中的队员完成作业后归队。
5. **营地**：结算带回的物资，喂饱全队（人越多吃得越多），建造/升级设施、修理改装武器、招募幸存者，第二天再出发。

设计原则：

- 每局 5–10 分钟，"再贪一个点还是现在走"是核心抉择。
- 开局顾予安、夏之遥两人；地图救援扩编至最多 8 名存活者（`RosterState.MAX_LIVING = 8`，PROJECT_TEMP）。历史名册最多 10 人，阵亡永久保留；有空位且有未登记候选时可再次救援。右侧头像、营地名册与出发复核沿用有界滚动列表。
- 数值都是临时值，改动在 PR 中说明。

## 4. 首个关卡类型："海边町·商店街路口"

尺寸：约 3×3 个街区的等距地图，一屏看到约 1/3。

分区：

| 区域 | 内容 | 作用 |
| --- | --- | --- |
| 中央路口 | 十字路口、斑马线、电车站台、巴士停靠点 | 出生点与登车光圈，开阔、好集合 |
| 商店街（东北） | 便利店、售货机 ×2、杂货铺 | 食物主搜刮点，路灯多，夜里最亮 |
| 运河与石桥（东/东南） | 运河把地图分成两半，只有石桥和一座小木桥能过 | 天然瓶颈，适合集火守桥；也会把队伍拆散 |
| 住宅巷（西/南） | 低矮民宅、自行车棚、小神社 | 可选搜刮点（工具、废料），巷子窄、视野差 |
| 港口仓库（远端） | 码头、集装箱、渔具仓库 | 高价值点（武器/工具箱），离巴士最远，风险最大 |

搜刮点（示例，最终数量由生成器决定）：便利店（食物）、售货机 ×2（少量食物，快）、杂货铺（货币）、自行车棚（工具）、港口仓库（武器/工具箱，耗时长）。

僵尸压力（随时间）：

- **白天前段**：零散游荡者，集中在住宅巷和港口；
- **黄昏**（倒计时后 1/3）：危险等级上升，从地图边缘和运河两岸持续刷新，开始向噪音/队伍聚集；
- **入夜**：刷新加快、出现成群，主要从远端涌向中央路口；路灯下视野好，暗处看不清；
- 撤离时巴士发动会吸引附近僵尸，登车光圈需要有人守。

登车区域：中央路口的巴士，车头朝向主路，车灯在夜间照亮前方扇形区域；小地图上始终显示巴士图标。

## 5. 当前范围与后续验证

六个界面已接入共用冷调样式，首页已接入独立像素背景；世界素材的进一步像素重绘另行推进。后续视觉工作应先以真实角色和场景切片校准像素尺度、2:1 几何、闭合屋顶与遮挡，再扩展素材。

公开复测入口是 `python tools/godot.py check`，所有输出仅放被忽略的本地目录，测试不得使用真实玩家进度。交互、导出和人工观感分别记录当前候选结果；本规范不声明这些验证已完成。

精确收据实现已接入，正式生存门禁仍为 **BLOCKED**。继续保留原存档校验、死亡身份与唯一结算约束；检查退出 0 不代表已证明可靠恢复，视觉更新也不改变该门禁状态。
