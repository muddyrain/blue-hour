# M14-WORLDGEN-01：道路、地块与尺度

范围仅为新旅程普通行动的街区结构、场景尺度和只读紧凑 HUD。所有数值为 PROJECT_TEMP。角色原画面尺度、125 基准移速、默认镜头0.82、主/可选奖励及原工作时间保持。

## 冻结与所有权

新营地 build6 增加严格 `worldgen1` 标识；行动仍使用 generated9 的探索语义，新增完整认证的 `worldgen` 扩展，布局单独升级为 layout5。rules10/world15 的战斗、工作、人物、支援、收据及恢复字段未变，因此不为编号一致升级它们。未知标识、缺字段、伪造布局/对象/收益均拒绝。旧 build5/layout4/world15 继续走原构造器、原数量与原政策；更旧分支和终局也保持。

WorldgenGeometry 先生成贯通巴士路与有界道路分割，再组装有用途的地块及不同建筑簇。WorldgenScale 是新布局的共享尺度规格；旧 NeighborhoodArt 不变。WorldgenLayout 在完整几何上使用 ExplorationLayout 的原对象净空和导航证书，加入车树后重新计算门、对象及原刷怪候选的真实路径。最多三次尝试，之后同尺寸同主题使用明确的确定性分割回退，绝不返回旧行列图。

几何、道路图、地块、建筑变体、物体与站点均在创建行动时冻结，完整描述参与原精确收据与兼容指纹。静态证书只缓存完整不可变描述；实际人物、工作、携带、时间、伤亡及恢复仍归 Expedition / SearchAssignments / 原事务所有，归航只由 FrozenSettlement 确认。场景及 HUD 不生成收益或改任务。

## 空间与素材

小中大沿用2560×1920、3584×2688、4608×3456。建筑数量从地块的连续门面、后院、住宅簇和仓储组合产生。普通建筑宽256–320、大商店480、仓库512；主街224、支街128、尽端96、路缘36、门口净空48世界单位。建筑等比显示，原屋顶分层与脚点遮挡继续使用新实体门口/碰撞。本轮36张样本的实际建筑范围为小10–18、中18–31、大26–42，六展示21–31；上沿略高于建议调试区间，因为院落后排需要保持可读的建筑密度，不额外授予互动收益。地图对角线在125基准速度下的理论直行下界仍为25.6/35.84/46.08秒，实际寻路依障碍更长。完整巴士进出 sweep、停靠、上车和集合区在生成与最终道具碰撞后保护。

本轮新增同风格果树及采空树，内置生图工具生成后按授权裁切/缩放，来源与SHA记录在素材清单。旧布局继续使用旧果树，避免改变已冻结碰撞/门口表现。道路、路缘、建筑门阶及接触阴影从冻结几何绘制，复用项目原地面材质，不使用参考图或设计整图作背景。

## 验收边界

开发前固定展示种子 `worldgen-v1-showcase-01` 至 `06`（medium/commercial），另3规模×3主题×4种子。签名排除种子、ID、美术、平移、镜像与坐标微扰，并给出连接、分支/环路和地块组合指标。总览明确标为生成布局，不替代正常入口截图。

当前 Mac 原生后台验证；自动 viewport 输入不称物理键鼠，30fps编码不称显示器帧率。普通中型流程、暂存后新PID继续与部分撤离为主流程；小大只加载/路线，旧world15一条继续代表，三四人HUD另用受控数据。正式生产门禁保持 BLOCKED。
