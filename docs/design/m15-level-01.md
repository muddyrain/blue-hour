# M15-LEVEL-01：任务组织关卡

已有四类每日任务、种子道路/地块、独立派工、车树、救援、携带、威胁与巴士。本轮增加局部用途倾向、主点组合、真实路线比较与任务卡事实说明；全部新增政策为 PROJECT_TEMP。

新旅程仍为 build6，仅将 `journey.build.worldgen` 标识设为 `{version:2, policy_id:BH_LEVEL_V1}`。行动仍为 generated9/rules10/world15，worldgen 扩展使用 version2/revision1；layout5 增加严格生成输入 `level_task`，exploration.level 冻结路线。旧 marker1/policy3 的 M14 R2、build5/layout4 及终局继续原构造与认证，不从新政策重生成。

LevelPolicy 在既有道路分割后仅调整一个合法局部地块用途。补给优先组织同地块/同街排的两个不同食品点，第一点仍在中远区；装备在原仓库/修理铺中选择深入主点，附带资源靠近主路线；救援选择具有多栋建筑的住宅簇门口，缺少合法住宅簇则拒绝该次生成。周围主题与全部建筑资源继续复用，不把三种任务锁为三张固定地图。空投沿原户外回收、一次性增援与来源链。

新政策的三个尝试及一个同规模同主题回退都涵盖几何、最终道具碰撞、站点与路线摘要失败。每个动作完整冻结种子、任务、地块、建筑、对象、站点、主目标、原预算及路线；渲染、继续和支援只读同一描述。LevelSummary 从最终导航冻结巴士往返、主点间路径、一个可选点的完整额外路线。共线格点压为同一折线段，保留每次转向与端点，不减少地图内容或改变寻路。

静态估算明确单人串行或双人同时分工、125基础速度与工作因子1，取较慢成员返回；单目标方案第二人留车。原20秒巴士就绪、3秒发动与登车/驶离表现单列。现场个人因子、加入者、战斗与编队以实际流程日志为准，估算不是安全倒计时或人工手感结论。任务卡按真正目标站点分别计算主收益和其余可搜上限；救援说明当场同行与生还归航后的营地登记。

新路线摘要及成功匹配证明复用原 ValueProofCache：键为完整不可变输入，成功后深拷贝保存，读取隔离返回；不按 seed、ID、文件名或时间戳偷跳检查。变更输入、失败或外部修改返回值不能命中旧证明。历史业务相等语义与精确 journal 编码保持；营地普通 JSON 不被另造的逐位浮点认证取代。公开检查覆盖新政策、来源/目标/地块/收益篡改及新缓存边界。

Expedition/SearchAssignments 仍拥有实际移动、工作、战斗、携带和原巴士规则；原 ProductionProgress/RunTransaction/ReceiptJournal/FrozenSettlement 独占保存、持久 ACK 与唯一归航。不增加奖励、保存器、移速调整或死亡迁移。当前只验 Windows 源码与后台原生；正式视觉、人工连续手感、导出、物理输入及其他平台分别保留未验，生产发布门禁仍 BLOCKED。
