# M38 突围与固守

以合入 PR #44 的 `main` `2f0669b7880f5656b13edbee610d353d7c1cd7d4` 为基线，包含复审提交 `4a8417b237a3abb09008c7674e102c0c7f14442a`。五项内容同批接入新普通旅程，新增数值均为 PROJECT_TEMP。

| 内容 | 来源与作用 |
| --- | --- |
| 整备工陆景川 | 既有救援池 `crew_5`。现场确认接纳后揭晓，确认生还归航后可减 3 币维修费。工坊和整备工取较高折扣，最低 1 币。 |
| 救援锤 | 第 3 天起普通工业装备行动的露天武器主点。原确认归航带回待修实例。10 币维修标价，伤害 48、间隔 1.25 秒、起手 0.32 秒，54 单位内正面 75° 命中一个合法目标。 |
| 缓冲内衬 | 工业装备主点为未持有者保留一份被动奖励。装配后爆囊冲击 ×0.65。 |
| 抑制脉冲 | 第三项能力样本，每次出击可用一次。12 秒内指定三类感染者的直接近战命中伤害 ×0.50。 |
| 爆囊感染者 | 合资格行动中首个暮色常规增援可以替换为爆囊。54 HP、移速 34。68 单位内合法接敌触发 0.90 秒警圈，命中 20 HP，冻结停读条、击倒取消、有效墙体遮挡挡住命中。 |

任务卡、进场、定位、读条和接纳重试统一显示「待救援幸存者」。真实立绘、姓名、职业与人物详情由确认接纳的原事实开启。营地登记以生还归航确认结果为准。M36、M37 各自沿用原动作、装备、能力目录和收据合同。

原作机制方向与证据来自开发包。GOG 1.7.0F2 的对应精确参数为 UNKNOWN。

## Mac 验收矩阵

| 编号 | 结果与证据 |
| --- | --- |
| T0 | 以 `m38-camp-6` 的陆景川和 `m38-rescue-15` 的沈听澜比较任务卡、场上标记、读条、详情和结果。接纳前暂存及写入失败重试保持匿名，接纳后暂存只揭晓原候选。确认生还后才登记，未接纳的撤离保持匿名。 |
| T1 | 正常流程通过三项能力、救援锤、内衬和整备工的回收与归航确认。装备来源和实例身份保留，重复确认返回同一收据。 |
| T2 | 两套构筑各从原营地装配，拒绝重复装入同一能力。实际维修标价 10，整备工在营时 7，营地建设工坊后 6。已确认阵亡的样本用定向合同检查资格。 |
| T3 | 用同一普通感染者的实战伤害路径得到 4→2→4。正常 B 进程在 88.13 秒同时启用两项能力，恢复后仍分别到 92.13 秒与 100.13 秒。 |
| T4 | 普通 B 用救援锤实际命中一名敌人。定向几何对照验证锤最多一人、斧最多三人、墙体阻挡和 68 单位范围边界。定向实战的冲击为无内衬 20 HP、有内衬 13 HP，圈外完整释放扣血为 0。冻结暂停读条，普通 A/B 均出现击倒取消。 |
| T5 | 普通 B 保存并跨进程继续时，出击快照指纹一致，包含能力与爆囊计时。购买、维修、爆囊写入分别注入故障，重试只扣款或释放一次。爆囊定向样本通过原 `BATTLE` 记录确认一次阵亡。 |
| T6 | 在隔离档继续 M36 V1 与 M37 V2 的代表途中样本，分别恢复 1 和 2 个已用能力事件，核对快照和原归航确认。 |
| T7 | 备份并复用同一营地字节，两路都走实际巴士确认。1280×720 和 1024×576 核对整备与战场信息。原生窗口离屏，观测点均未获得焦点。 |

普通流程使用正常界面与保存入口，自动驱动视口输入和模拟时钟。定向样本为控制变量会安排位置、时钟或初始生命。物理输入、导出包、其他系统与正式性能验收待测。正式生存发布门禁仍为 **BLOCKED**。

普通路线的收据链在分叉前超过 8 MiB。本轮将进程内收据缓存上限调整到 32 MiB，每次仍读取原文件并核对精确内容。初次离屏试跑检测到窗口获得焦点，最终捕获使用项目现有 Mac 后台限制，三次进程在记录点均未获焦点。
