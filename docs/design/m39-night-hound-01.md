# M39 夜间感染犬

从合入 M38-R1 的 `main` `2718ff542dc56317a219efe35bc45de7abb9cf34` 开发。2019 年经典版公告支持夜间出现僵尸犬的方向。该版本与 GOG 1.7.0F2 的具体犬参数均为 UNKNOWN。本项目数值为 PROJECT_TEMP。[Pixelsplit 1.0 公告](https://store.steampowered.com/news/posts/?appgroupname=Deadly+Days&appids=740080&enddate=1569421769)

## 出击合同

- 新普通旅程的 `night_hound_policy` 为 1。仅第 3 天起、符合 M38 资格的普通工业装备行动冻结同版本标记。稀有、救援、练习和终局沿用各自规则。
- 入夜后，首个实际成功生成且底层抽签为普通的空闲名额可生成一只夜间感染犬。尖啸和爆囊保留优先权，满员或位置非法不消耗犬名额。已有生成记录跨暂存继续，即使犬已击倒也不能补第二只。
- 犬有 32 HP、追击速度 64、近战距离 28。停步锁定一个目标并压身 0.45 秒，到时对同一目标重新检查距离、视线和可攻击性。命中扣 5 HP，命中或取消后间隔 0.90 秒。全域冻结暂停移动和计时，扑咬接触画面由原成功命中驱动。
- 犬沿用原导航、伤害门禁、战斗死亡和归航事务。锁定目标、剩余起手和间隔复用原敌人字段。M38 与早期已冻结世界按原策略继续，旧策略会拒绝犬身份。

原创 SVG 透明图集从游戏内同屏试样发展而来。东、东南、南、东北、北五个源向加三个镜像共用固定脚点。包含警戒、四帧低伏追击、压身、扑咬、受击、倒下与倒地。[图集与素材来源](../../assets/PROVENANCE.json)
