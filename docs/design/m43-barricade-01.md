# M43 街区路障

新旅程通过 `campaign.barricade_policy: 1` 启用。第 4 天起，既有中型普通补给槽可冻结一处车辆路障。认证保留巴士、站点、下车及刷怪点可达性，并要求从同一近侧点到同一原补给站点至少缩短 320 世界单位。找不到合格位置时沿用原行动。路障位置和判定阈值均为 **PROJECT_TEMP**。

可沿原街道绕行，也可在原空袭门禁允许的车旁地面落弹。车体在闭态阻挡通行且不能落弹。成功确认的空袭在实际半径及无遮挡范围内命中车体锚点时开路。炸偏仍按原空袭结算并进入 20 秒冷却。路障没有额外物资、经验或增援。

行动验证以完整地图和原站点重建标记。闭态复用独立的车辆覆盖网格，开态复用原导航，敌人与队员读取同一投影。开路从原空袭接受历史派生，存档无需新的开路字段。写入前失败保持闭态与原冷却，重试沿原待确认请求。闭态恢复检查角色位置与有效路径。无标记行动继续按旧输入和指纹验证。
