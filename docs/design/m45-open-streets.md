# M45 开放街区功能样板

从 PR #51 已审提交 `e515ded0f6d1544bd2a2b621e1cef75165ec5525` 开发。功能样板沿用 R3 的开放道路、普通车道等候、逐个登车和整车出图规则。场景使用已有建筑、铺装、植被和堆物。多方向巴士使用临时绘制的顶视轮廓。

## 进入试玩

```sh
python3 tools/godot.py run --open-streets --godot <锁定版 Godot>
```

打开「开始试玩」，在营地通过巴士打开任务列表并选择符合条件的普通大图。此入口使用 `.local/m45-open-streets` 隔离进度，可用 `--profile` 指定其他项目内隔离档。新旅程的策略写入原营地快照。「继续试玩」沿原事务恢复同一行动、同一布局和现场状态。

## 地图与撤离

- 大图尺寸为 12,288 × 8,192 世界单位，主干道接到地图边界，分区通过种子切分成街块。商业西进东出、仓储北进西出、住宅东进北出。停车点由种子在直车道内挑选，和交叉口保持距离。
- 车身、转弯扫掠和车门到集合区使用同一份冻结几何。建筑、围墙、可搜对象及有碰撞的装饰在布置后接受联合校验。原小／中图、特殊行动和原有旧世界继续按各自的认证路径运行。
- 新大图对主目标路径设暂行距离上限。近中远可选点继续按真实路径分布。生成尝试有限，认证失败时回到已具备合法任务路径的原布局。
- 在原结果写盘成功后，根据应撤离名单依次播放登车。车门关上后车辆沿原车道起步，镜头跟到地图边缘。整车越界且跑完外侧缓冲后才显示归航结算。确认入库仍由原收据事务负责。
- 大图导航使用相同的 16 单位脚点网格，按障碍占地栅格化，长路线使用跳点。样板的大图导航证书单独限量缓存。

## M45-R1 街道断面

新的隔离旅程使用开放街区修订 2。普通主干道宽 224，两侧铺装各宽 32，车身宽 80。转向线路在主路交叉口使用 384 × 384 的局部铺装，集合点位于车门一侧，距路缘 48。布局、绘制及转弯扫掠校验共用这些道路边界。

仓储区在等候点附近用短支路组织两侧的门面。普通沿街门面距支路路缘 64，装卸地块保留较深前场。深地块允许背排建筑和步行连接，货箱沿用现有场景件。商业、住宅共用道路断面，并保留不同的店铺、住家与院子。

原宽街旅程继续按修订 1 重建。营地、行动和布局分别保留各自已有的修订标记，继续时仍校验原布局和收据。小、中图和特殊行动沿原入口生成。尺寸为 PROJECT_TEMP。

## M45-R2 仓储街区

新隔离旅程的普通仓储大图使用修订 3。沿用 R1 路网和停靠点，从停点最近的服务街交叉口找到四块相邻用地。车门一侧的主仓连接装卸院和绕仓步行路。对侧为连续仓房。短支路南侧布置检修后巷和两处场门贯通的围合货场。两个补给点继续使用原任务预算和结算。

其余地块先留路缘、转弯、登车、场院与通行净空，再补仓房和配套房。最小配套房实体占地 192 × 112，连屋面与门前、侧后通行共需 256 × 236。新增实体沿原建筑和导航接口认证，配套房可无搜刮权限。建筑使用项目自制占位素材。车辆、果树和房屋仍走既有站点预算。

旧仓储 R1 途中档、商业、住宅和特殊装卸行动保留各自冻结修订。样板几何不能认证时，普通仓储回到已认证的 R1 路径。
