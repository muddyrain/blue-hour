# M45-R4 种子化街区

从本地 R3 `ee842a5c4f958d92cafcc9e27da0553063935cb7` 继续。通过隔离开放街区入口新建旅程，普通大图使用修订 5。行动、地块和道具的数值均为 PROJECT_TEMP。

## 仓储路线

| 家族 | 道路和搜刮 |
| --- | --- |
| 临街主轴 | 一条支路横穿巴士所在的主干道。过街后沿装卸院到主库，第二处补给在同一街块。 |
| 环路围院 | 两条支路与外侧服务街围成可走的环。可从停靠侧直达主库，也可走外环到其南门。第二处补给在主库背面，拥有独立入口。 |
| 错位支路 | 停靠点两侧的支路在不同高度接入干道。沿服务房与路缘之间的侧巷进入装卸面，再转向主库门。副库随相邻地块净深布置。 |

家族由行动布局种子决定，候选重试保留同一家族，路网切分和地块陈设分别使用各自的稳定随机流。先确定巴士道路、局部连接、主次工位和走线，再细分外围街块。补给使用原两站预算，装备和普通空投使用实际主仓的站点。三个候选耗尽后尝试同族固定外围路网，再由原入口尝试对应主题的已认证旧修订。每次拒绝可从测试或选卡记录读取。旧修订的几何仍按原代码重建。

## 地块适配

全图地块从实际临街方向、建筑可见边界、门前和剩余空间派生候选。布置前预留路缘、车身扫掠、集合、工位与连接步道。仓储优先在合法退距内补无搜刮权限的附房，再按墙长和装卸院尺寸放置灯具、工具架、货箱和标线。商业复用服务房及停车退距，住宅复用院地、花床及附房。每块地的 `site_fit` 记录最小可建净尺寸、实际使用、未分配空地及原因。可建净尺寸含屋面轮廓、两侧各 24 单位、后侧 24 单位和门前 88 单位。场地预算随面积增加。

场景布置完成后才放置原可搜车辆与果树，随后联合认证全部门口、工位、巴士路径与仓储走线。布局只冻结语义槽和物理几何，`--bh-warehouse-art=signal` 从渲染层替换同一组 R3 占位资源。继续途中档仍读取原冻结地图，暂存、派工和结算沿用原事务。

## 复现

在项目目录运行下列命令。每次新种子使用自己的项目内隔离进度路径。进入「开始试玩」，点击营地巴士，选第 2 天的仓储大图「食物补给」。

```sh
seed=m45-r4-wh-002
profile="$PWD/.local/m45-r4-play/$seed"
mkdir -p "$profile/home"
env HOME="$profile/home" /Applications/Godot.app/Contents/MacOS/Godot \
  --path "$PWD" --rendering-method gl_compatibility -- \
  --bh-open-streets "--bh-rescue-seed=$seed" \
  "--bh-progress=$profile/run.enemy-v1.json" "--bh-audio-settings=$profile/audio.json"
```

临街、环院和错位型启动种子分别为 `m45-r4-wh-002`、`m45-r4-wh-045` 和 `m45-r4-wh-019`。引擎锁定为 Godot 4.7.2，使用 Compatibility 渲染器。正常继续需使用相同的隔离进度路径。
