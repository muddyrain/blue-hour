# M45-R3 仓储陈设与换图

新隔离旅程的普通仓储大图使用开放街区修订 4。先生成 R2 街块，再按仓房端头、实际路缘、装卸场与门口落点添加场地和副建筑。西侧附房和沿街行尾附房是原建筑列表中的实体，进入移动碰撞、射线遮挡及固定的屋面遮挡。它们是配套房，原派工和奖励预算由已有站点生成负责。门口、临街入口、绕仓路径和侧巷出口一起接受原导航校验。

A 作业带以绕仓通道为参照。B 从装卸场的边界生成编号、月台边和货箱。C 找主仓隔路的西侧街廓，并沿现有房体落窄附房。D 由连续仓房右侧的净宽生成铺装，接到两端步行面。E 顺沿街仓房的行尾接出工具房。装卸场和检修房可在其他街块复用，外围附房有数量上限。狭窄地块先保留通行，主样板无法认证时沿版本向下回退。原 R2 旅程仍重建修订 3 的地图与收据。

## 固定资源槽

尺寸以世界单位计。立式件以底部中心为锚，地面件以冻结矩形为锚。所有新件均无独立搜刮权限。

| 资源 ID | 物件 | 展示帧或实体占地 |
| --- | --- | --- |
| warehouse.storage.pallet_rack | 托盘架 | 帧 144 × 76，碰撞 126 × 26 |
| warehouse.storage.cargo_stack | 货箱与托盘 | 帧 88 × 60，新货组碰撞 72 × 25，沿用的货组读取原冻结碰撞 |
| warehouse.loading.bay_mark | 装卸位线及编号 | 贴地，按冻结场地矩形适配 |
| warehouse.loading.dock_edge | 月台接缝 | 贴地，按冻结边缘矩形适配 |
| warehouse.service.narrow_annex | 窄检修附房 | 帧 112 × 186，碰撞 112 × 144，屋面分界 132，门中心距左 55 |
| warehouse.service.end_annex | 行尾工具房 | 帧 112 × 176，碰撞 112 × 132，屋面分界 122，门中心距左 63 |
| warehouse.service.repair_kit | 工具柜与气瓶 | 帧 64 × 56，碰撞 52 × 22 |
| warehouse.service.work_mat | 作业带 | 贴地，按冻结矩形适配 |

| warehouse.alley.edge_prop | 边缘管线 | 帧 36 × 52，展示层 |

布局冻结的是槽 ID、实例 ID、位置和物理规格。场景渲染才通过 WarehouseDressingArt 选择贴图，默认使用 yard。向锁定版 Godot 的游戏参数传入 `--bh-warehouse-art=signal`，同一次启动会选择整组测试外观。既可新建行动，也可从同一 R3 途中档继续。生产替换在 WarehouseDressingArt 的资源表增加方案，将素材按槽内坐标、尺寸和屋面分界适配后装入图集。未知方案和无法裁切或空白的槽会记录提示，并使用该 ID 的默认占位。屋面遮挡和碰撞取自固定规格，方案名和素材路径只属于展示层。
