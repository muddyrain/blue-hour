# M45-WORLD 三主题街区

本轮在同一条本地分支接续 [R4 仓储布局](m45-seeded-districts.md)。已审祖先为 `ee842a5c4f958d92cafcc9e27da0553063935cb7`。隔离试玩用 `--bh-open-streets` 启用，正常流程从标题新建旅程，再经营地巴士选择实际签名任务卡。

| 主题 | 家族与入口 |
| --- | --- |
| 仓储 | 临街主轴先过街取补给，环路围院有前后工位和外环，错位支路沿服务房外侧切入。 |
| 商业 | 贯通商街沿相邻门面搜寻，市集侧街进出开放广场，超市后勤从卸货一侧进场并可沿后街绕回主门。 |
| 住宅 | 连排院落从同侧门前进入，错位侧巷沿院墙边转入，围合组团从两个端口进入院内。 |

大图沿用同一巴士扫掠规则。任务地块在其余街块切分前选定。开放街区修订 5 冻结家族、工位和实际道路。小图、中图使用原尺寸、任务预算和巴士流程，以 `scenery_revision: 5` 冻结随面积收紧的地块布置。玩法几何在全部陈设及可搜物加入后认证。条件不足时确定性重试及回退，旧旅程按自身版本认证。

工业空投装卸院、住宅救援院各自保留原几何生成和玩法检查。稀有冷库及军需站、泵站终局、广告牌目标地图仍由各自入口生成。侦察、路障和事件沿用实际布局和站点来源。版本、交互或结算合同未作迁移。配套房、地面和陈设复用仓库已有素材，外观方案只解析稳定槽位。

验收使用锁定版 Godot 4.7.2 和 Compatibility 渲染器。所有新增布局尺度属于 PROJECT_TEMP。正式发布门禁保持 **BLOCKED**。
