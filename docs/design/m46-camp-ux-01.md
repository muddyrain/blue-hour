# M46 蓝时驿站整备

营地页使用现有的角色、装备和营地资源。装备仓按真实实例查询，右侧对照目标队员的当前装备和所选武器。界面分别显示实例参数与持有人修正。配给或交换先显示两侧归属变化，再用稳定实例 ID 通过原营地编辑保存。仓库、工坊、队员、补给与巴士的返回入口共用同一营地状态。

## 设施和改装

新旅程使用 `campaign.midgame.version = 2`。首次确认归航后可用 12 币选一条路线。建成后至少再确认一次成功归航，才能用 10 币升二级。改动随原营地编辑收据入账。一级设施与 V1 旅程继续按原合同运行。

- 扩建补给架后，后续成功归航的设施应发为 3 粮。原粮食账本分别记录应发和实收，可由两值计算溢出。
- 建校准台后，普通就绪长管步枪可消耗 1 工具箱和 8 币安装一个方案。扩容为 7 发与 2.55 秒基础换弹，快拆为 3 发与 1.85 秒。实际换弹继续计算持有人因子，冻结世界绑定同一实例与方案。

新增数值属于 PROJECT_TEMP。设施版本与日期随原出击前态冻结，旧旅程仍使用原经济版本和新版营地界面。

## 出击准备

巴士先显示可返回的核验页。后台工作只读取营地快照，复用原行动生成和认证缓存。M46-R1 允许核验中返回营地并立即整备。重新打开巴士时先显示当前确认的配装。前态相同则沿用在途核验。前态变化后，只发布当前前态的核验结果。

行动卡就绪后，可选任务并在右侧核对当前小队的装备与支援。确认调用原出击事务。布局、奖励和任务身份沿已冻结的规则验证。

装备仓目标、武器持有人、交换预览和出击小队统一显示成员编号与呼号。实例短号可带或省略前导 `#`。

## 隔离复测

`python tools/godot.py check` 执行公开检查。Windows 原生驱动用 `python tools/m46_campaign_flow.py campaign --godot <固定引擎> --output <.local 内新目录>`。它使用独立 Windows 桌面、隔离档和原游戏业务输入。

正式生存发布门禁为 **BLOCKED**。
