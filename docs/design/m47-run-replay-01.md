# M47 标准旅程与跨局专精

普通标题的新旅程在首次确认时冻结 M45 的街区修订、开局专精及当时可回收的解锁集合。大图按主题选择街区家族与认证路线。小图和中图保留其尺寸，采用既有地块布置。专精不参与地图随机。已有旅程的开局和行动继续按保存时的版本验证。

| 专精 | 开局装备在第一被动槽 | 可回收装备 |
| --- | --- | --- |
| 搜集型 | 野外工具，搜刮和露天回收耗时 ×0.75 | 轻行束带，已部署队员步行速度 ×1.10 |
| 火力型 | 高压弹头，枪械直伤 ×1.20 | 导向弹匣套，最终换弹时长 ×0.90 |
| 支援型 | 急救绑包，基础治疗 Q 恢复上限 ×1.20 | 急救广播，每次出击一次，为室外未登车的受伤在场队员恢复最多 24 HP。优先最低生命比例，同分取较小成员编号。 |

至少两笔先于终局的成功归航确认后，泵站胜利加 2，全灭加 1。资料按进度路径绑定，从已确认的终局与归航记录验证。资料写入失败可重试，重复启动和确认读取同一旅程的经验记录。2 经验开放同专精，4 经验开放所有专精。装备的开放、当前旅程资格、实际发现与配装分别记录。

专精候选使用普通行动的第 3 个签名槽位，即商业或住宅的普通露天装备回收。主回收点 `cash` 已有普通被动奖励时，至多替换其中一个，当前专精优先，其余按共享装备 ID 排序。广播沿同站点的能力携带与确认流程占用一个原装备位。面罩和缓冲内衬维持原有来源。调查、工业装卸院、救援、稀有站点、终局和广告牌保持各自的奖励。玩家需实际回收并生还归航，确认后才能在营地配装。

《Deadly Days》提供了随机任务、三条成长路线和跨局解锁的原型思路。M47 的门槛、数值、奖励分配、站点和巴士流程属于 Blue Hour 的 `PROJECT_TEMP`。沿用项目现有素材。[经典版官方商店](https://store.steampowered.com/app/740080/Deadly_Days/) · [2018 年开发公告](https://store.steampowered.com/news/posts/?appids=740080&enddate=1540571844)

## Windows 复现

使用项目锁定的 Godot 4.7.2 和 Compatibility 渲染器。普通隔离启动可运行 `python tools/godot.py run --godot <Godot.exe> --profile .local/m47-play`，在标题点击新旅程。定种子的自动复跑使用 `python tools/m47_run_replay.py victory --godot <Godot.exe> --output .local/m47-replay --seed m38-wave-01`，保留同一输出及隔离档路径，再运行 `reward` 阶段并使用 `m45-r4-wh-002`。自动复跑使用隔离桌面的真实界面、战场、巴士和原结算。定向伤害、故障和恢复场景另行标记。
