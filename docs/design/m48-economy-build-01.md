## 资源与设施

`EconomyActions` 在完整旧动作来源上冻结 `economy_source`，包含战利品档位、逐站工具预算和五金标记。五金仅保存被改变的原字段；验证先恢复并完整认证原动作，再按同一规则重建整个新动作。`DailyActions.matches` 仍从真实出发营地重算候选。

第 3 天起，普通工业装备行动的已认证可选点可回收 1 工具，与工坊建设无关。第 3/6/9……天，slot 2 的随机机会优先改为五金补给；已确认广告牌情报先兑现，固定调查和终局位置保持。五金主点为原露天工作点，工作基时 12 秒，产 2 工具；合法副点另产 1 工具，主点不再发武器、被动或能力。工具只有真实搜完并成功归航确认后才成为余额。

工具单位身份为归航事务、站点和序号的组合；同一单位只绑定一个消费编辑。营地建设、出售、制作、升级、组件和弹匣通过 `EconomyBuildV1` 纯提案接入原 `CampEdit`。请求固定操作 ID 和预览前态；旧预览失效，写入或确认失败沿原事务重试。售出实例保留历史，活跃库存和新配装禁止引用售出身份。

新经济来源中的完整动作使用 `BH_M48_ACTION_GZIP_EXACT_V1` 无损封装，保留精确原文及压缩字节的哈希和长度；受原 1 MiB 上限约束。解码后仍认证完整动作及站点。来源解压使用受 1 MiB 原上限约束的固定长度，并重压比对完整 GZIP 字节，拒绝尾部或多成员。本轮未发布调试档的完整动作表示可显式读取，比较时先恢复完整来源。

C 的两次正常长路线分别在第 15 天约 59.75 MiB 和第 26 天约 52.40 MiB 触及原收据预留门槛，失败与已确认原件保留。新增 M48 收据默认使用显式 `BH_M48_ZSTD_EXACT_JSON_V1`，同时读取本轮早期 `BH_M48_GZIP_EXACT_JSON_V1` 和历史 V1。完整原 V1 字节无损往返，业务指纹、链哈希、绑定和确认语义保持；M47 不能套用新标记。真实大记录的引擎探针为原文 2,144,675 B、GZIP 584,402 B、ZSTD 279,358 B。解压原文仍受单条 4 MiB 上限，收据目录 64 MiB 和营地 1 MiB 上限均未增加。传输解码后继续原完整来源、业务和转移校验。ZSTD 固定长度解压前按[官方格式](https://raw.githubusercontent.com/facebook/zstd/dev/doc/zstd_compression_format.md)检查单帧头、内容长度、窗口、块边界和精确结尾，再以固定引擎重压逐字节核对。

目录读取每次检查完整结构并重读全部源字节。只有与完整认证前缀逐条完全相同时才复用纯证明；单条缓存命中也必须把新读完整字节与 `cached.raw` 比对。新 M48（含本轮早期 V1）已认证结果在进程内使用有界 ZSTD 原生值缓存，校验私有缓冲区哈希和单帧边界；不允许对象反序列化或落盘，每次返回独立字典。真正旧 M47 仍走原结果路径。

当前完整认证前缀的原字节预算为 64 MiB；缓存只在逐字节相等后引用该前缀的同一个 `PackedByteArray`，共享字节只计一次。每次前缀发布都在短互斥区重新绑定实际引用，失去共享的条目重新计原字节并按 LRU 逐出。缓存持有的非共享原字节、压缩原生值或旧结果序列化估计及每条 2048 B 元数据共用原 32 MiB、256 条上限。这是持有缓冲区的记账预算，不是 RSS 上界；解码与完整业务校验仍在锁外，未知字节仍完整认证。

真实 C 的 150 条记录热扫完整读取 150 文件，DTO 命中 150、Exact 解码 0，耗时 1.080356 秒；缓存记账 20,349,922 B，另共享前缀 31,640,581 B。首次完整认证仍需 267.743616 秒，首次独立扫描为 43.725745 秒。保留这些冷读慢值，不把热读结果当成启动或恢复速度。

固定引擎的动态 GZIP 解压在已结束流仍有尾字节时可能不消费输入，负例曾触发 300 秒超时；改为已界定的固定输出长度，随后确定性重压比对，保留同组负例。[Godot 4.7.2 源码](https://raw.githubusercontent.com/godotengine/godot/4.7.2-stable/core/io/compression.cpp)是定位依据。新增整备和归航确认先渲染等待状态，冻结前态与请求，提交期间阻止重复编辑；失败后才显示实际重试入口。已有来源的原生试玩启动先显示核验遮罩，再由单个后台线程依次执行原 `inspect → refresh_catalog`，线程持有原 session / Writer 直至 join；主线程在完整核验和界面初始化完成前消费输入，随后复用同一结果。资料核验可能合法补发缺失资料记录，不能当作纯读；退出也先 join 再释放 Writer。首次等待画面和完整标题可用耗时分开记录。同一 20 档隔离原件的启动补验中，首等待画面为 1.229295 秒，完整标题为 169.058194 秒；原生子视口持续绘制，最大观察间隔 621.517 ms。此值不代表显示 FPS 或全部操作低于 100 ms。同一 20 档及继续增长的当前旅程又完成四次真实归航，确认回调为 21.820–57.094 秒，资料读取 27.546–30.291 秒；这些长历史慢路径仍须在复审中评估。选卡后台计算只消费不可变快照，并在发布前重核当前前态；启动是原 session / Writer 的独占交接，二者不并发，保持原来源验证、资料发布及持久确认语义。

## 武器与构筑

普通小/中/大装备行动战利品档为 1/2/3，稀有为 3。等级为 `clamp(1 + floor((day - 2) / 3) + int(loot_grade >= 3), 1, 5)`；直伤系数依次为 1.00/1.10/1.20/1.30/1.40。普通/增强/稀有权重依档为 60/30/10、45/35/20、25/40/35。品质不另乘伤害；兼容词缀为轻快、延伸、枪械穿透和击倒补弹。

## 本轮主平台结果

同一第 5 天、72 币／4 粮／4 工具的真实共同营地，种子参数 `m48-economy-015`（旅程种子 `cc29156722aa0aa0cd640b3204a970b5`），按原绑定路径顺序分叉。A、B、C 分别在第 8／14／23 天确认胜利，归航总数为 6／12／21，均无人死亡；最终币／粮／工具为 78／0／4、7／0／1、18／7／8。B 总投入 104、出售收入 19；C 总投入 188、出售收入 84，其中基础经营 80，三枪与全槽覆盖额外投入 108，未推演未执行的低投入 C 终局。

B 的五级自制卡宾实伤为 25.2；同一实例较早四级时确有主伤 23.4、穿透 11.7，两个实测分开记录。C 的自制霰弹实际击倒补弹，强化医疗实际治疗 68／70 HP；三能力与部分换弹在独立 PID 保持完整世界指纹并合法归航。组合交易另从真实共同营地完成制作、组件更换、出售、维修再出售和独立进程回读。

同机、同引擎、同精确布局的各三次冷进程，M48 首反馈均低于 100 ms，选卡可操作中位 5.928398 秒，M47 基线 5.975930 秒。换枪首反馈最初约 154 ms，补真实保存等待后为 6.044–6.773 ms；完整确认耗时及最大帧间隔仍按原始样本列出。所有场上固定步进为测试加速，墙钟不是玩家通关用时。
