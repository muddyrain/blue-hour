# M49 整局性能与可玩性收尾

M48 已经 PR #55 普通合入 `1494ff91b141d96661f4c50c5c0337204225282c`。
M49 从该实际最新 main 开发，保持 Draft 复审，正式生存发布门禁 **BLOCKED**。
本轮只验 Windows、固定 Godot 4.7.2 与 Compatibility；所有性能阈值为 PROJECT_TEMP。

## 玩家行为

启动、继续、专精资料、营地保存和归航核验使用原进度服务的一条串行执行通道。
等待层显示真实操作及经过秒数，阻止冲突编辑和重复提交。已确认余额在事务完成前保持。
窗口关闭或 Esc 记录退出意图，等待当前操作到达安全边界；已经开始的写入不能被 UI 取消。
途中恢复的核验尚未消费快照时，退出直接保留原快照；已经开始出击或消费快照后，退出须先用原暂存链保存实际世界。

保存 ACK 已成立但专精资料核验失败时，界面明确显示“已保存，资料待同步”，保留重试；未核实的资格不能用于新旅程。
写盘前失败和提交后丢确认仍由原 ProductionProgress/RunTransaction 的原请求重试，只结算一次。

## 证明复用

ReceiptJournal 原来只有一个共享完整前缀，切换 live 与归档会反复替换。
现在按目录保留有界的完整原字节证明。每次仍枚举实际目录、读取所有原字节并检查绑定、链接和代次。
只有全部相同的字节才复用历史纯证明；变化或未知内容仍完整解码和业务认证。
CatalogProgress 在完成这次核验后，可复用该前缀内的纯投影。事件文件、唯一 run/root、资格和发布检查每次仍执行。

记录缓存保持 32 MiB，所有前缀与投影合计保持 64 MiB；边界、索引和元数据计入预算。
共享引用变化后重新计费，淘汰后可冷认证。字节比较、编码和大值复制在锁外，锁内只处理有界元数据和发布。
返回投影独立，DTO 校验失败回退重算。没有新的持久化索引、编码格式或业务权威。

## 精确恢复边界

出击刚确认时安全退出，先完成原巴士下车与原队员显示刷新，再冻结世界。
否则首次捕获的零显示偏移会在恢复时被正常显示更新改变，破坏精确往返。

探索来源记录生成时将队员编号表示为 float，与 Exact 原有的数字解码表示一致。
原整数值可精确表示，编码字节与业务意义不变；探索、工作、时钟与旧档校验均未放宽。
固定 4.7.2 已确认嵌套数组严格比较会区分 int/float；旧实现会在实际移动后第一次能力 ACK 之后拒绝后续来源前缀。
回归覆盖现场/收据/恢复前缀一致，以及删除探索、改换成员和重写工作点仍被拒绝。

## 复测

公共入口仍为 `python tools/godot.py check --godot <固定引擎>`，新增多目录与投影严格负例。
原生驱动 `tools/m49_flow.py` 使用 Windows 独立桌面和子进程专属用户目录。
`tools/m49_sources.py` 只允许本轮 `.local/m49`，在没有活跃 Writer 时保留、核 SHA 并恢复到原绑定路径。
`tools/m49_writer.py` 用两个真实原生进程验证同一写者互斥。

完整性能、原始帧间隔、故障收据、样本身份及 T0–T10 结论保留在私有审阅包。
M48 Mac A/B/C 仅作为未改经济与战斗公式的历史证据；不代替 Windows 本轮验收。
物理键鼠、人工手玩、导出及其他平台如未实际执行均不推定通过。

默认主场景的进程至标题观测上界，0／5／20 归档分别为 5726.684／16317.865／32321.363 ms；20 档确认作业为 32660.236 ms。
首反馈约 5.5 s，0 档启动 p95 为 86.584 ms；均有未达项。长档验收驱动的冷标题仍约 497 s，未消除首次完整历史认证成本。
正常入口和重型驱动、引擎内部与进程创建口径分列；原始帧、探针、计时和失败不删除或剪裁。

公开检查按实际影响综合 80 个不同组、121 份素材，并保留原失败与定向补跑，不宣称一次全绿。
正式门禁保持 **BLOCKED**；未验的人工手玩、物理输入、导出及其他平台不推定通过。
