# 普通感染者的显示稳定性

ANIM-02修正普通感染者的三个表现问题：朝向临界角附近频繁换向、导航短停造成步态重启、接近队员时显示偏移突跳。逻辑脚点、AI、速度、HP、伤害、碰撞与保存合同不变。

ActorVisual对普通感染者使用方向滞回；短停保留行走相位，停得足够久才回待机；既有贴身显示偏移按时间平滑追向同一目标值，没有扩大留距。倒地保留最后显示脚点，尸体不重新站立。幸存者、疾奔与重压继续原路径，枪口与LOS计算不变。

17项定向检查覆盖方向临界、小幅抖动、短停/长停、偏移连续、原事件优先级及幸存者路径；505项动作检查继续验证多方向和枪口。后续[V1图集](m5-art-infected-01.md)只适配素材帧号，行为断言保留。

Mac受控原生连续画面已完成专项审阅；公共投影另做克隆检查与短窗口核实。Windows、物理键鼠、显示器呈现与自然任务全程仍待验，不因固定60fps录像宣称卡顿消除。

**ANIM03_CONTACT_OVERLAP_OPEN。** 角色路径仍可能进入相同逻辑脚点，动态角色分离未实现；Y排序只决定遮挡次序，平滑显示偏移不能保证分开。导航留距、撤销旧路径或动态分离属于后续移动/接触合同，不在本表现修复中。正式生存仍受[未修复的哈希缺陷](../KNOWN_LIMITATIONS.md)阻断。
