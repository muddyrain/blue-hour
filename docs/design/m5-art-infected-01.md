# 普通感染者V1：美术与动作实机候选

M5-ART-INFECTED-01只替换普通感染者的美术与姿态映射。普通敌种key、逻辑位置、寻路、动态接触、速度、HP、伤害、冷却、攻击时刻及保存合同不变。ANIM-03_CONTACT_OVERLAP_OPEN，P0继续PARTIAL / NO-GO-PRODUCTION。

## 资源与接入

新增assets/infected_v1/normal/，五张独立源图分别为E、SE、S、NE、N；SW、W、NW明确镜像，运行时八方向可用，不是八张独立画稿。灰白肤色、灰橄榄便装与失衡站姿根据私有概念方向重绘，比例和斜俯视参考现有幸存者；未复制幸存者身份、武器或旧普通感染者的橙衣图。

每张1254×1254 RGBA，4×4归一化格子，每格313.5源像素，16个实际姿态，共80个源格。源输出保持原字节，没有逐帧按alpha外框缩放或居中。固定脚点、方向/镜像及动作表见atlas.json；SE经图像工具统一留白修正，使用独立固定脚点。身体显示比例0.26，其余角色仍用原比例。

NormalInfectedV1预载五张源图，只派生普通感染者的纹理、帧、镜像及作者脚点；没有逐tick读盘或重建整套帧资源。ActorVisual保留ANIM-02的方向滞回、短停相位、贴身偏移平滑及死亡锚点。原MotionAtlas继续负责幸存者、疾奔、重压。无新增快照字段；原时钟和朝向仍由原owner恢复，不在本任务承诺完整存档可靠性。

当前开发候选默认使用V1，旧normal_full.png原字节保留。仅开发对照的引擎用户参数--bh-normal-art-legacy可选择旧图，不写入规则或存档；使用时仍须指定隔离进度/音频路径。它不改变正式生存默认入口，也不是玩家设置界面。

素材由内置image_gen辅助生成和定向修正，如实登记于PROVENANCE与资源元数据；模型标识未由工具公开，不填推测值。原生生成输出、提示词与处理记录和失败材料保留在私有任务目录；没有新增许可证，也不把私有执行包或参考图整包提交。

锁定Godot 4.7.2.stable.official.ed1daf0bf、GL Compatibility。新增172项定向资源/状态检查，原17项稳定性与505项动作检查保留行为断言，旧动作行号按V1契约适配；完整公开入口15组通过，仍报告存档PARTIAL及生产BLOCKED。
