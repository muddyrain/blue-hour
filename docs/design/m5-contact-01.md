# M5-CONTACT-01：脚点接触与兼容边界

从公共 main `9f6d0e42e5aa7436278606735da026ff5502e76c` 继续。风险为 PERSISTENCE/HIGH_RISK：接触移动会改变战斗及途中档继续的因果。本轮实现接触规则，保留伤害、生命、移速、冷却、攻速、28px近战、LOS、射击和原保存事务。没有合并私有研发历史，没有补绘素材或切换普通默认。

## 原因与规则

原 `FieldActor.advance` 直接沿静态路径移动。追踪每0.7秒更新，接近目标时停止重规划却保留了旧路径；路径终点仍可能是幸存者脚点。静态导航只避障，不处理角色占位。平滑显示偏移和Y排序无法阻止两人逻辑同点。

`FieldContacts` 负责20px脚底圆的动态分离；该数值来自既有静态脚半径10，属于PROJECT_TEMP。普通追击到24px且静态直线可达时清除旧路径，闲置目标超过26px重新追击，给28px近战留下余量。三类感染者仍使用原行为、攻击判定和数值。

- 幸存者与敌人仍按原先阶段推进；各阶段内部按稳定成员/敌人ID排序，不按节点创建顺序。完全相等的目标距离也以稳定ID破除对称。
- 每个路径微步不超过4px，逐段检查静态障碍、地图边界及其他脚底圆的扫掠相交；受阻时尝试有限的侧向方向，禁止直接穿过另一个脚点。到达路径点后继续消耗该微步剩余位移预算，每微步最多16段，避免无接触时被路径点降低实际移速。
- 同向中间网格点被另一个脚底圆占用时，只在下一段静态直线可达的条件下推进路径索引，避免追着不可到达的点绕动。保留返回/让位处的转折及最终目标；索引仍按原路径字段保存。真实World四向主动穿越既检查间距，也要求实际越过感染者。
- 每阶段最多64微步。异常大的delta只截断该次可接受移动时间，计时器仍接受调用者delta；不以无限求解补齐卡顿时间。
- 非法同点初态用确定性配对投影逐步恢复：每次投影最多2px，每人每调用累计不超过 `min(80*delta,8)` px，最多六轮。对角恢复被边界挡住时只尝试四个固定的非内向方向。恢复投影检查静态障碍，允许在已有坏拥挤内传播，不保证不可能容纳的空间里瞬时分开所有人。
- 闲置队友可有限侧让；单通道对向队友只搜索六个可容纳的让位处，把协同绕行写成普通路径。没有额外让位计时器、随机数或恢复后丢失的接触缓存。无可用让位空间时允许阻塞，不穿墙或隐藏角色。
- 死亡/倒地、隐藏、室内搜集者不占位；角色退出世界后不参加求解。暂停在原 `Expedition.step` 入口返回，恢复暂停时不执行分离。

动画在接触处理后更新，以最终实际位移计算速度；感染者步态随该速度推进。ANIM-02方向滞回、短停保相位、平滑贴身偏移及V1图集保持。没有透明化、大幅显示推移或修改攻击判定来掩盖穿叠。2.5D纵向身体遮挡仍正常存在，不承诺所有贴图轮廓完全分开。

## 保存合同

新途中世界的原family BUILD后缀为 `+M5-CONTACT-01-1`，compatibility包含接触参数。除原路径/索引/行为/时钟外，显式保存已有表现缓存 `_walk_rest`、`_contact_display`、`_contact_initialized`，保证恢复暂停画面与下一步连续。

认证历史与恢复执行分开：`SortieSnapshot.problem` 对历史BUILD保留原严格字段集合，新BUILD要求新增字段完整且类型合法。未知BUILD、旧BUILD添加新字段或新BUILD缺字段都拒绝。历史业务哈希、收据精确编码、链、binding、事务与ACK owner未改。

`SortieSnapshot.apply` 在任何世界恢复/claim之前拒绝旧接触语义，返回 `WORLD_CONTACT_BUILD_MISMATCH`；界面明确要求使用原兼容版本，未消费或改写原暂存。旧已完成CAMP及其历史世界仍可认证；不能因为历史链含旧世界而把营地一并判坏。旧可执行版本同样不接受新接触BUILD。不做默默迁移，不在暂停恢复时挪动角色。

## 检查与限制

公开 `tests/contact_separation.gd` 使用真实FieldActor/Expedition，覆盖四向交错、八人完全同点、反向创建顺序、静态墙角及地图边界、窄路对向队友、非占位状态、大delta、1600px无接触直路的实际移速、三敌种真实攻击和暂停。原505/17/172动作检查、80项收据编码及保护断言保留；额外接触暂存驱动走原营地、暂停菜单和保存owner。

原死亡驱动把全队开火冷却设为999，在新接触站位下可能造成旁观者额外阵亡。仅该显式诊断改为让指定对象沿真实路径走到队友实际射程外、只抑制该对象开火，其他人正常防守，再用原可见近敌按钮及AI确认死亡。不改HP、伤害或人数断言；仍严格要求两次救援后的四人、一次指定阵亡、补位后五历史四活人，以及死者记录不变。训练仍要求真实一食物报价；新补位者可能已由真实击杀练满特质，因此按原报价规则选择最低稳定ID的可训练存活者，不降低等级或注入食物。

同输入前后录像使用隔离练习场、实际导航/攻击与自动输入；四主方向各5秒，再加双人六敌拥挤。连续原始影片为正常1280×720尺寸，无变速或插帧。固定60Hz MovieWriter用于可比视觉，不是显示器FPS证明。原生墙钟帧时间、包内暂存和安全矩阵按[实际验证](../VALIDATION.md#m5-contact-01mac接触修复)分层报告。

Windows当前不可用，按用户要求先交Mac证据。Windows EXE/PCK、Windows独占文件句柄/路径别名/TerminateProcess及独立桌面矩阵均未验证；Mac SIGKILL不能替代Windows语义。物理键鼠、显示器呈现流畅性、任意断电与未提供内部历史原件未验证。P0生产NO-GO与正式生存BLOCKED继续保留，PR待用户审阅后决定合并。
