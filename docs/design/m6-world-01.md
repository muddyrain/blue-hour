# M6-WORLD-01：可玩街区样板 V1

基线为 PR #7 的6deac3c，前置尚未合并，分支codex/m6-world-01以codex/m6-rogue-01为base，依赖#7/#6/#5。来源是本轮明确项目要求，新增布局、搜刮分配、演出时长均为PROJECT_TEMP，不宣称原作实测。

## 空间与资产

正常每日行动使用WorldActions V2；三个有限模块是青禾商业街、柳巷街区、北岸仓储街。每块2560×1920、12栋、覆盖八种建筑。三个模块改变楼体/任务位置与路侧巴士相对位置；目前道路轴线共享，后续可增加更丰富的道路拓扑。不是无限地图或室内探索。

BuildingLibrary只映射代码拥有的资源和每类门锚点/碰撞深度。WorldLayout的同一实例描述驱动建筑脚点、碰撞、射击遮挡、门口、导航、出生、相机、巴士路线和恢复。生成一次选择已验证的有限模块，不做无界重试；严格规范重建拒绝任意额外几何。模型包含车身扫掠车道、路侧停靠、安全集合区、真实前门、上下车落点和左右地图边缘。街灯、花槽、箱子和短围栏是明确可穿过的装饰，首版未作为实体障碍；源图装饰也不另造碰撞。

八类楼体来自内置image_gen原创生成，每类独立PNG，未输入原作图像或直接使用概念图。高分辨率可编辑栅格源在assets/world_v1/source（.gdignore避免导出），运行精灵512×640、脚点256/608，按alpha裁切和等比缩放；屋顶/前墙在引擎分层，后方己方使屋顶透明。清单和哈希见[manifest](../../assets/world_v1/manifest.json)。未制作多朝向或每类外观变体。

## 站点与唯一收益

每次行动4—6个有稳定ID的站点，绑定建筑、资源类别、额度、工作量和唯一武器许可。钱粮沿用V1预算范围，按整数拆分，不把整卡奖励复制到每栋。卡片显示“可搜获上限”；只有实际完成点增加携带，部分搜刮即可归航。站点工作量集中为30秒，保留原个人Trait倍率。搜刮Trait仍按原钱/粮两个类别各最多一次累计，避免点数增加放大成长。

Expedition持有站点实际进度、完成和唯一工人；WorldSites仅做纯值校验与收益推导。原WeaponInventory负责唯一实例，FrozenSettlement与GrowthRules回读同一站点事实。未知站点/额外字段、畸形进度、预算/地图/行动身份不符均拒绝。

## 版本与兼容

RogueActions V1 CONFIG与RogueLayout V1保持原字节；DailyActions按显式版本分派旧历史认证。新版行动version2、规则data_version3、世界version4，互相绑定，不扩大旧规则或旧世界含义。营地schema111、精确编码、收据/代次、死亡、饥饿、成长及唯一结算owner保持。

旧完成营地按原认证保留身份、钱粮、成员和装备，并可开启V2行动。正常入口在claim前拒绝旧固定/旧V1途中世界，提示使用原兼容版本，保留原件及未消费代次，不回退旧营地或清空进度。固定旧开发入口保留。

## 巴士时序

出击先登记原行动，再沿横向主路实际驶入2.4秒、下车1秒；演出期间战场时钟/敌人/伤害不推进，移动、搜刮、援救和撤离意图均被拒绝。暂停冻结演出，跳过到同一初态；此时暂存也规范到同一已登记行动的安全初态，继续不重放进场。

真实全员集合和原同一步伤害/死亡优先后，先由原owner发布RESULT_READY，再播放0.9秒登车和2.8秒驶离。表现只移动车和已冻结的生还队员，不再计算战斗、资源、口粮或日期。完成/跳过显示同一预览，原确认提交只执行一次。驶离期间关闭后，原首页明确“继续”路径确认既有冻结结果，不重放行动。失败不播放成功驶离。
