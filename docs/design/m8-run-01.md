# M8-RUN-01 · 第一条可通关短局

正常“开始试玩”新建短局 V1，经过四次准备归航后进入固定终局“突破封锁”。准备期继续原任务、街区、搜集、救援、XP、训练、维修和配装。没有新奖励池、营地建设或第二个结算器。所有新增数值均为 **PROJECT_TEMP**。

## 玩家流程

| 已确认准备次数 | 本次行动 | 基础刷怪间隔 |
| --- | --- | --- |
| 0、1 | 阶段1：筹备，三个原合法候选 | 原值 |
| 2、3 | 阶段2：突围，三个原合法候选 | 原值 ×0.90 |
| 4 | 唯一终局：突破封锁 | 原值 |

暮色/夜间系数在这个基础间隔上应用一次。阶段不改敌人生命、速度、伤害、24总容量、地图规模或站点预算。计数依据实际确认的准备归航，与初始营地日历无关；提前撤离也消耗一次。浏览、出发、暂存、失败保存和重复确认不推进。

终局仍可搜集原场地物资和提前撤离。未击败首领只按实际所得及原口粮结算，不胜利、不增加准备次数；下次是新事务和新战场。途中继续则恢复同一首领及战场，不补生命或弹匣。

## 破阵者 V1

首领复用重压感染者素材，以独立地面轮廓、名称、生命条、红色危险圈和预警进度识别。场地仍由原合法街区生成；描述冻结首领身份、参数与经原导航验证的出生点，和巴士/角色出生区保持距离。

| 参数 | 最终候选 | 附件初始值 |
| --- | --- | --- |
| 最大生命 | 960 | 480 |
| 移动速度 | 26 | 26 |
| 近身范围 / 伤害 | 28px / 24 | 28px / 10 |
| 近身起手 / 冷却 | 0.9秒 / 2.2秒 | 同左 |
| 落击选择范围 / 危险半径 | 340px / 60px | 同左 |
| 落击伤害 / 预警 / 冷却 | 32 / 1.2秒 / 4秒 | 12 / 1.2秒 / 4秒 |

首次真实两人流程在约11.6秒击败初始480生命首领，每人只受12伤害，因此集中提高三项数值。新候选主动避让约20秒获胜；静止对照的一名队员接近耗尽生命。该定向自动输入样例说明规避有实际作用，不代表已完成人工手感或广泛平衡签核。

两攻击互斥，起手冻结目标/落点；落击不追踪。到期重新检查范围、LOS和原室内保护，户外回收者仍可受击。伤害使用原 `take_damage` / 持久伤害门禁和死亡写者。生命首次达到60%、30%分别请求最多两名普通感染者，经原合法刷怪 owner 和含首领的24容量处理；不足时保存实际原因，不重复补生。普通三敌种策略不变。

## 唯一状态与保存

新建111旅程在原 `journey.campaign` 内保存短局V1身份、已确认准备数、结果与结果事务。`CampaignRules` 纯读配置，`CampaignActions` 冻结V6描述；新规则7 / 世界9显式分支绑定完整阶段、场地与首领参数。原营地、事务、READY/ACK、精确编码、原文证明缓存和唯一归航写者保持。

首领是原战场敌人0号，计入原生成和击败账本；独立行为只产生稳定请求，由集成适配器交原战斗/刷怪 owner 处理并确认。世界9保存实际生命、起手/锁点/剩余计时、冷却、阈值处理结果、未确认请求及已部分处理的命中身份，同时保存实际召援敌人、原地图/队伍、弹匣和换弹。恢复不得重置、重复攻击、召援或补弹。

击败凭证来自原致命射击及成长/XP接受的同一事件，绑定本次事务和唯一首领；界面没有可写的胜利开关。胜利还要求本次合法终局、至少一名实际存活者经原巴士撤离、原饥饿结算后仍存活，以及明确确认保存。全灭优先失败。未保存时只显示预览；失败保留原冻结候选，禁止新行动和新旅程，重试不重复结算。确认胜利后可查看结果、队伍，不能继续刷任务；明确新旅程生成新身份和种子，旧旅程按原归档机制保留。

旧111完成营地没有campaign字段，继续原每日V5；旧途中按已承诺的显式版本继续，不按day推算阶段。原世界6隐藏空投等既有拒绝边界不放宽；原件保留。历史兼容指纹、永久死亡、饥饿和奖励语义不改。
