# 按影响选择验收

入口为[AGENTS](../../AGENTS.md)，用[任务记录](codex-task-template.md)简记本轮范围。M6-PLAYABLE-01起，以下规范替代此前因战斗持久化因果自动扩大完整HIGH矩阵的规则。

## 风险与检查

| 分类 | 必需检查 |
| --- | --- |
| DOCS/LOW_RISK | 来源、隐私、链接、差异与相关工具隔离检查。无运行变化不录像或导包。 |
| GAMEPLAY/MEDIUM_RISK | 当前系统上的流程预检、定向回归与最终候选公开check，必要界面证据。普通玩法整合不因涉及战斗自动运行完整存档矩阵。 |
| PERSISTENCE/HIGH_RISK | 实际修改协议、事务、恢复、死亡身份或唯一结算合同的部分，按影响补安全回归，列出合同和对应性质；标签不代替分析。 |

保存目录/路由变更需验稳定路径、隔离、重启继续与旧入口/原件保护，不自动推导全部矩阵。编码变更验严格负例与往返；结算变更验READY/ACK及唯一领取；死亡身份变更验不可复活与营地优先；锁/发布变更验竞争、中断和主备保护。原有有效校验保留，不放宽旧档拒绝掩盖错误。

## 执行顺序

1. 核仓库、分支、HEAD、工作区、依赖PR和在途写者。预检入口、隔离目录、稳定ID、UI状态和超时，先跑小范围实际流程。
2. 使用真实界面事件或既有业务接口实现/定向验证，不直接写玩家状态伪造完成。SCRIPT ERROR/ERROR即使退出0也不是通过；反复失败先定位，再扩大检查。
3. 最终输入确定后记录源/资源或tree、未跟踪输入、引擎/渲染、驱动/参数和profile，导包时记录包SHA。完成最终公开check及受影响流程，失败修复后只重跑受影响检查。
4. 复用前核相关依赖内容、引擎/渲染、驱动/参数、profile与对应包身份，保留原日志/日期。未知不当相同，源码/包内/原生/物理输入分别报告。未修改且明确无关的强杀、锁竞争和历史档矩阵不重复，旧包不能冒称新包通过。
5. 交付差异、结果/缺口和启动方式，按授权commit、正常push和创建PR。未合并依赖采用独立stacked PR并写明base，不向前置分支追加代码；merge/Release单独授权。

## 平台与数据

开发默认只验当前系统；发布前再覆盖计划发布平台。明确Mac即可时，不因Windows缺席阻塞开发交付，未验平台写NOT_VERIFIED，正式生产门禁保留。

自动验收仅用临时隔离profile，正常试玩用稳定独立目录；不拿真实玩家进度测试，不自动覆盖、迁移或回退旧档。后台验收不控制当前桌面或抢占焦点；内部viewport事件/原生离屏渲染注明层级，无法完成的人工观感、物理输入与显示呈现检查如实注明。

仅录必要的正常尺寸演示及截图，说明自动输入、剪辑或模拟加速；固定录像不证明显示器FPS。不默认生成多套媒体、跨机bundle或完整历史备份。

## 计时、磁盘和交接

记录主要阶段UTC和返工原因即可，可用既有task_timing或轻量账本，不为计时工具扩大任务。可见区间含等待，重叠不相加；完整任务、隐藏推理、token和重连归因UNKNOWN。不改模型设置或承诺未测提速。

.local隔离产物先定预算，收尾盘点增量/大目录。保留失败、唯一受验包、存档/备份和历史原件；不自动回收历史，本轮冗余临时副本可在原字节无损归档并核SHA后处理。原始profile/日志及私有ZIP不公开。

按本轮需要制作一个轻量审阅ZIP，含方案/差异、关键原始结果、必要媒体、兼容结论、失败与未验项，核CRC/SHA并独立解压。工具测试只在工具实现受影响时运行，不因引用工具或改规范而扩大检查。

## 同目录文件所有权

先冻结API与文件清单，按不相交文件委派子代理；共用任务分支与开发目录，默认不新建worktree。主代理独占Git、共享接线和引擎；子代理不stage/commit/切分支、启动导入或修改全局UID缓存。主代理在并行实现时推进共享入口，统一排队局部检查，确认文件交接后冻结输入并完成最终验收。记录各自开始/完成和实际重叠，等待不相加。

交付只保留本轮必要候选、轻量私有审阅ZIP和媒体；清理前核原字节/保留位置，报告实际增量与回收量。旧任务大目录、玩家档和历史原件不因本轮预算自动删除。
