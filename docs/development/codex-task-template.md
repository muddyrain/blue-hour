# 公开开发任务模板

先读[公开AGENTS](../../AGENTS.md)、[公开plan](../plan.md)现行区及[分级执行规范](codex-execution-efficiency.md)，按需查相关功能/架构与已知缺陷。填写实际值，未知写UNKNOWN，不能以占位值当验收证据。

```text
任务ID与已审公共基线：实际公共HEAD/分支及工作区；保持独立公共历史，不合并内部开发祖先。
玩家可观察目标：具体操作、反馈、可复核结果；纯工具说明开发者收益。
唯一写入目录 / owner / 并发约束：项目根、单写者、桌面执行者、其它写者状态。
风险与依据：DOCS/LOW_RISK、GAMEPLAY/MEDIUM_RISK或PERSISTENCE/HIGH_RISK；实际影响与自动升级条件。
必读合同/失败：当前功能、设计/兼容、失败原件的相关范围；缺证据明确报告，不伪称已取得私有矩阵。
本轮范围与限制：实际文件边界、未开放能力、保留的发布门禁。
驱动预检与定向：入口/依赖/版本、输出父目录、隔离profile、稳定ID、窗口/按钮/焦点/状态、屏障及超时、短冒烟。
冻结身份与最终验收：源/资源SHA或tree加未跟踪清单、引擎SHA/版本/渲染导出模板、驱动/夹具、参数/schema/profile、EXE/PCK；风险对应完整案例。
旧结果复用与失效：原日志SHA/日期/层级，新旧身份逐项比较；变化影响的检查和重验范围，不跨协议/引擎/包复用。
媒体与输入层级：无界面/原生/包内/OS物理输入分别写，纯LOW无媒体NOT_APPLICABLE。
阶段计时、失败及磁盘：新run路径、真实UTC区间并集/重试原因、未记录/隐藏项UNKNOWN；容量基线/预算/最大任务目录、原件保护。
Git授权：本地提交、公开push、PR、merge、Release分别记录当次实际授权，不沿用已结束任务权限。
交接完整性：精确公开差异/测试/限制；当次要求私有ZIP时只用已提供的环境流程，唯一包核CRC/SHA并独立解压，内部原件不公开。
```

顺序固定驱动预检→实施与定向→最终输入冻结→风险所需验收→文档/提交/交接。LOW验工具/链接/来源/差异；MEDIUM加相关完整检查和冻结后的Windows包/原生视觉；涉及游戏协议、死亡/冻结结果/战斗存档因果自动HIGH，严格执行旧格式/负例/往返/跨PID/唯一结算/READY-ACK/死亡营地优先/锁多写者/强杀/主备保护及最终包。缺所需矩阵就保留门禁，不把公开check子集当完整发布验证。

失败不覆盖，WATCH/OS-NOT-VERIFIED/NO-GO-PRODUCTION不随效率优化关闭；未知不推算思考时间，不宣称未经对照的提速，不改模型设置。RECORD_READBACK:RECORD_HASH仍未修，相关修复另立HIGH任务。
