# 开发任务记录

先读[AGENTS](../../AGENTS.md)、[当前状态](../plan.md)、相关功能/架构与[执行规范](codex-execution-efficiency.md)。记录实际值，未知写UNKNOWN。

```text
任务/目标：玩家可观察的完成条件。
基线/分支：实际HEAD、工作区、远端、前置PR和新PR base；保留无关修改和私有历史。
原作证据：官方公告记录版本、发布日期与链接。本机实测单列版本、环境、观察与条件。未经核实的数值记 UNKNOWN。
本项目现状：先记录改动前的行为、参数来源和基线样本。
本轮采纳或改造：说明采用的体验目标、项目内实现、差异和依据。
对照验收结果：记录实际流程、可复核证据、结果与未验项。
范围/合同：实际改动、未改合同、风险及需要的定向回归；不因战斗自动扩大完整存档矩阵。
环境/数据：当前系统、固定引擎/渲染、独立测试profile、稳定试玩目录与旧数据保护、后台/物理输入边界。
预检/实现：小范围实际流程、稳定ID、UI状态、失败原因及修正。
最终验收：冻结身份、最终公开check和受影响流程/保存检查；未测平台与人工观感。
复用：依赖/条件不变的有效结果及原日志；变化后的必要重验。
计时/磁盘：主要阶段UTC及返工原因、隔离产物预算；完整任务/隐藏推理/token UNKNOWN。
交付/授权：提交/推送/PR base与依赖、简短报告、启动方式、必要媒体与一个轻量ZIP；merge/Release单独授权。
```

先定向，后最终检查。协议、事务、恢复、死亡身份或唯一结算合同改变时按实际影响补对应安全性质。未修改且明确无关的强杀、锁竞争和历史档矩阵不重复。开发默认只验当前系统，发布前再验计划发布平台。始终保护真实数据、原件与有效校验。
