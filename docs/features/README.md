# 功能与入口

## 开发试玩默认

正常启动或 `python tools/godot.py run --godot <engine>`，无需玩法参数。开始试玩→营地→任务→搜集/救援→发动与集合→预览→确认→回营成长。继续试玩使用固定 `user://playable-v1/run.enemy-v1.json`，旧档不自动迁移。正式发布门禁保留。

开发者可用 `run --legacy-entry` 进入原双人旧入口，或 `run --enemy-trial --profile .local/demo` 使用显式隔离111入口。下表系统已接入默认试玩，仍为PROJECT_TEMP。

| 范围 | 实际能力和边界 |
| --- | --- |
| 救援 | 林知秋、沈听澜、陆景川等原创候选；单图一个目标，原确认后当场入队、战斗、归航。多个候选不等于同图多目标。 |
| 名册 | 四名存活/五条历史。真实阵亡后可救剩余候选，死者身份/成长/装备历史保留，不复活。 |
| 成长 | 本人普通XP与Trait分开；食物训练消耗本人确认的资源，已有唯一保存链提交。 |
| 武器 | 卡宾18伤/0.65秒/210距，长管32伤/1.30秒/315距；个人Trait另影响有效值。实例有独立等级/品质/词条，维修不重抽。 |
| 敌人 | 普通54HP/34速/4伤；疾奔36HP/34→58；重压96HP/23速/6伤和0.5秒可规避前摇。数值不是原作精确事实。 |
| 夜间 | 沿既有时钟阶段及合法屏外出生规则混合敌种。自然风险仍待独立平衡。 |
| 动作 | 五身份八向移动/瞄准及射击/受击/倒地；普通正背动作、新疾奔/重压姿态。部分过渡和敌人镜像明确保留。 |
| 保存 | 严格事务和暂存代次，原确认数据不可撤销；精确收据候选已接入，不保证任意帧位/中断可恢复。 |

搜集员仍按原规则进入建筑隐藏；救援原10秒进度有短反馈，不声称有不可见室内动画。归航仍需实际全员到巴士，结果确认才结算；不是退出到首页即回营。

详见[限制](../KNOWN_LIMITATIONS.md)及[架构](../architecture.md)。

## 项目要求与经典版证据

本页及五篇文档按当前Blue Hour已实现行为编写，不把旧版本“尚未开放”的描述套到111，也入口变更见M6设计，旧进度不自动迁移。

| 来源等级 | 本公开文档的含义 |
| --- | --- |
| PROJECT_TEMP | Blue Hour原创角色、参数、人数、成长/装备/救援和生存政策；实际游戏验证也不升级为原作证据。 |
| LOCAL_VERIFIED | 只用于经典Deadly Days特定本机版本与条件的实际观察。本次文档同步没有操作原作，不新增该等级事实。 |
| OFFICIAL_HISTORICAL | 经典版官方历史消息，只支持当时描述，不能推导V1.7.0F2精确参数。 |
| COMMUNITY_CLAIM | 社区经验不当作本机验证。本文不据其补造公式或权重。 |
| UNKNOWN | 原作精确概率、公式、人数及其他未证实机制继续未知。 |

旧截图按各自版本标注，不能证明当前数值、动画或可靠性。完整索引见[真实截图及版本](../screenshots/README.md)。**精确收据传输候选待审，正式生存NO-GO/BLOCKED。**
