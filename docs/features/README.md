# 功能与入口

## 普通默认

保留两人旧旅程、双固定地图、搜集、自动交火、巴士、营地与原保存边界。当前111原型不会静默替换普通默认。

## 显式111隔离原型

用tools/godot.py run --enemy-trial --profile .local/demo进入独立目录。旧旅程不自动转换；继续时使用同一目录。新增能力均PROJECT_TEMP。

| 范围 | 实际能力和边界 |
| --- | --- |
| 救援 | 林知秋、沈听澜、陆景川等原创候选；单图一个目标，原确认后当场入队、战斗、归航。多个候选不等于同图多目标。 |
| 名册 | 四名存活/五条历史。真实阵亡后可救剩余候选，死者身份/成长/装备历史保留，不复活。 |
| 成长 | 本人普通XP与Trait分开；食物训练消耗本人确认的资源，已有唯一保存链提交。 |
| 武器 | 卡宾18伤/0.65秒/210距，长管32伤/1.30秒/315距；个人Trait另影响有效值。实例有独立等级/品质/词条，维修不重抽。 |
| 敌人 | 普通54HP/34速/4伤；疾奔36HP/34→58；重压96HP/23速/6伤和0.5秒可规避前摇。数值不是原作精确事实。 |
| 夜间 | 沿既有时钟阶段及合法屏外出生规则混合敌种。自然风险仍待独立平衡。 |
| 动作 | 五身份八向移动/瞄准及射击/受击/倒地；普通正背动作、新疾奔/重压姿态。部分过渡和敌人镜像明确保留。 |
| 保存 | 严格事务和暂存代次，原确认数据不可撤销；已知浮点哈希拒绝未修，不保证任意帧位/中断可恢复。 |

搜集员仍按原规则进入建筑隐藏；救援原10秒进度有短反馈，不声称有不可见室内动画。归航仍需实际全员到巴士，结果确认才结算；不是退出到首页即回营。
