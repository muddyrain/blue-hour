# Blue Hour 阶段顺序与验收

1. **核心玩法与内容规则。** 用正常入口跑通同一种子的速攻和整备战役，确认资源、阵容、配装、敌情与真实结局构成取舍。确认旧档、继续、唯一结算与最终公开检查通过后再进入批量内容阶段。
2. **批量加入幸存者、感染者、武器、道具和技能。** 每类至少覆盖一个从获得或遭遇到实战产生区别的正常路线。确认来源、身份、效果、结算与旧档边界，比较代表内容的策略差异。
3. **统一贴图、动画与正式特效。** 在已稳定的玩法和内容上统一表现。按实际游戏尺寸检查可读性、战斗反馈、原生性能和发布平台导出，再走正式发布验收。
